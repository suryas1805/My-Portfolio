🧑‍💻 Portfolio Website
A modern, fully responsive developer portfolio built with React, Tailwind CSS, and Framer Motion, featuring dynamic project data fetched from a backend API. This site showcases my skills, projects, and contact details in a sleek, animated UI.

🚀 Features:
✅ Fully responsive design
✅ Smooth animations using Framer Motion
✅ API-driven project data
✅ Tech stack badges for each project
✅ Contact form integration
✅ Optimized performance and accessibility
✅ Easy to customize and deploy

🛠️ Tech Stack
Frontend:
React + Vite
Tailwind CSS
Axios (API requests)
Framer Motion

Backend:
Node.js + Express
MongoDB
